## Checks run

### axe-violations
0 violations across tags `wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22a, wcag22aa` on all 8 routes and both states (Playwright + axe-core 4.12). Only baseline violation was `color-contrast` on the CTA button (finding #1), now resolved. **Pass.**

### keyboard-operable
All flows are native and keyboard-operable: nav links, category links, joke-card share links, copy `<button>`, FAQ `<summary>`/`<details>`, PWA install/dismiss buttons. Skip-link → main and share-control focus asserted in Playwright. **Pass.**

### no-keyboard-trap
No focus-trapping components. The only "dialog" (PWA install bar) is a non-modal bar with a reachable Dismiss button; focus is never captured. **Pass.**

### visible-focus
Removed `focus:outline-none`; added a site-wide `:focus-visible` outline (3px cyan `#00e5ff`, offset 2px) on every interactive element. Hand-measured indicator contrast vs dark background ≈ 12.8:1. **Pass.**

### focus-order-logical
DOM order is source order (static Astro, no reordering/`tabindex>0`). Order: skip-link → logo → primary nav → main content → footer nav. **Pass.**

### skip-link
`.skip-link` ("Skip to main content") is the first focusable element and moves focus to `<main id="main-content" tabindex="-1">`; asserted by the keyboard test. **Pass.**

### reflow-320
No horizontal scroll at 320px on any route (Playwright asserts `scrollWidth ≤ clientWidth+1`). Fixed the overflowing email token. **Pass.**

### zoom-400
Layout is fluid (`clamp()` type, `max-width` containers, flex/grid, relative units); no fixed pixel widths or `overflow:hidden` clipping. 320px reflow (equivalent to 400% zoom on a 1280px viewport per WCAG 1.4.10) passes on every route. **Pass.**

### zoom-not-disabled
Viewport meta = `width=device-width, initial-scale=1` — no `user-scalable=no` / `maximum-scale`. **Pass.**

### reduced-motion
Added `@media (prefers-reduced-motion: reduce)` neutralizing transitions/animations and the joke-card tilt. Playwright emulation confirms 0 long-running animations. **Pass.**

### text-contrast
All text ≥ 4.5:1 after fixes. Hand-measured: muted body/nav/lede 7.1:1; card-title accent `#ff2d78`/surface 5.14:1; cyan links 11.9–12.8:1; CTA button white/`#e11d63`–`#c9134f` 4.63–5.69:1; footer copyright 6.6:1; neon gradient `.site-title` — worst point (pink `#ff2d78`) 5.52:1 on dark. **Pass.**

### ui-contrast
Focus outline (cyan, ~12.8:1) and button/control fills exceed 3:1 against adjacent colors. Card boundaries carry a background/shadow delta beyond the faint 1px border, so identification does not depend on the border alone. **Pass.**

### headings-landmarks
One `<h1>` per page; `<h2>` for sections/FAQ. Landmarks: `<header>`, `<main>`, `<footer>`, uniquely-labelled `<nav>` (Primary/Footer/Breadcrumb). axe landmark/heading rules clean. **Pass.**

### accessible-names
Icon-only controls all named via `sr-only` text ("Share on Facebook", "Share on X (Twitter)", "Copy link") or `aria-label` (PWA "Dismiss"). Decorative SVGs `aria-hidden="true"`. Logo `<img>` has `alt`. **Pass.**

### alt-text
Only meaningful raster/vector image is the logo (`alt="Yo Mama Jokes Central"`). Inline share/copy icons are decorative and `aria-hidden`. No `<img>` missing `alt`. **Pass.**

### target-size
Social/copy buttons 40×40px. Nav links given `inline-block` + padding for ≥24×24px hit area. **Pass.**

### status-announcements
Added `role="status" aria-live="polite"` region announcing copy-link success. No other async status (static content site; no cart/toasts/async saves). **Pass.**

### descriptive-links
Link text is descriptive ("See More Jokes", category names, "fat jokes", "contact page", breadcrumb labels). No "click here"/"read more" generic labels. **Pass.**

### aria-current
Active header/footer nav item marked `aria-current="page"`; breadcrumb current node already used `aria-current="page"`. **Pass.**

### framework-a11y-lint
No jsx-a11y-equivalent plugin ships for this Astro static site; Astro's compiler a11y diagnostics are the applicable linter and emit **0 warnings** on build, and `astro check` reports **0 errors / 0 warnings** (only unrelated pre-existing hints). **Pass.**

### wcag-checklist-disposition
Every applicable WCAG 2.2 A/AA criterion dispositioned across this report (Pass) or the skip list (N/A). Forms/media criteria are N/A (no forms, no time-based media). No blank/undecided rows. **Pass.**
