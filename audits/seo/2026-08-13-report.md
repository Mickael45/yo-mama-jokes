## Re-run this pass

### manifest-installable
**Candidacy (rev 3): PWA — yes.** A browse-and-return jokes site with
frequently appended content; manifest already shipped.

**Finding, fixed this pass (would have been recorded 🟠 moderate — the aggravated case: the
manifest advertised an install the OS then mangled).** The `maskable` icon entry pointed at
`/og/logo-512.png` — **the same edge-to-edge tile served as the "any" icon**. Its art reaches
**305 px** of the 204.8 px safe radius (49% over), so the OS mask cut the gradient frame and the
outer letters of "MAMA" off installed home screens. Fixed in **`820fe35`**: new
`/og/logo-maskable-512.png`, the tile scaled into a 320 px box on a full-bleed `#0c0a13` field →
max radius **197.3 px**, inside the safe zone; the manifest now points the `maskable` entry at
it and `scripts/pwa.mjs` precaches it. `scripts/make-maskable-icon.mjs` repeats the render.

**Installability — PASS (after the fix).**
- `<link rel="manifest">` once, `layouts/Layout.astro:41` →
  `https://yomamajokescentral.com/site.webmanifest` → **200 `application/manifest+json`**
- `display: "standalone"`, `start_url: "/"`
- icons `/og/logo-192.png` (any), `/og/logo-512.png` (any), `/og/logo-maskable-512.png` (maskable);
  the first two are **200** in prod, the third ships with the next deploy
- `npm run build` completes (29 pages) and re-emits `sw.js` with the new icon precached

**Live-vs-repo:** prod still serves the old manifest (maskable → `/og/logo-512.png`) until the
next swarm deploy picks up `820fe35`.

**Offline: own service worker** (`scripts/pwa.mjs`, `/sw.js` → 200): network-first for
navigations, stale-while-revalidate for the rest, cache keyed to a content hash so a deploy
purges it.
